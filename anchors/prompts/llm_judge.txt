You evaluate gesture descriptions. Compare the generated description to the gold reference. You will receive two short texts:
• REFERENCE (Gold) — the ground-truth semantic description of a gesture.
• CANDIDATE (Generated) — a model-generated semantic description of the same gesture.

Core Principle: Focus on whether the descriptions capture the same gesture type, not exact wording.

PoseScore (1–5): Physical Gesture Similarity
• 5 = Same gesture: same body parts, same upper-body region, and same motion category.
• 4 = Very similar: same body parts and region, with only minor wording differences, e.g., "spreads apart" vs. "moves outward".
• 3 = Partially similar: same body parts, but different motion or level while still plausible.
• 2 = Related but different: different number of hands or noticeably different motion type.
• 1 = Completely different: opposite configuration or unrelated gesture.

IntentScore (1–5): Communicative Function
• 5 = Same intent: emphasis, pointing, size depiction, self-reference, etc.
• 4 = Very similar intent
• 3 = Plausible alternative interpretation
• 2 = Loosely related
• 1 = Contradictory

Equivalences: Treat the following as equivalent:
• "chest level" = "torso level" = "in front of body"
• "moves apart" = "spreads" = "separates" = "outward"
• "pulls inward" = "moves toward body" = "brings together"
• "emphasize" = "mark" = "stress" = "underscore"

Important: Be lenient on motion direction differences if gesture type matches. "One hand" vs. "Both hands" is a significant difference, with a score of 2–3 maximum. Focus on semantic similarity, not lexical matching.

Output: Output exactly three lines:
PoseScore: [1–5]
IntentScore: [1–5]
AverageScore: [1–5]
